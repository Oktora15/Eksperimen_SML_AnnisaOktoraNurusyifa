# Membangun Model

Folder ini mengandung semua artefak untuk kriteria Machine Learning dan advanced tracking.

## Isi folder
- `modelling.py` : training model menggunakan DagsHub dan MLflow manual logging.
- `modelling_tuning.py` : training dengan hyperparameter tuning dan manual MLflow logging + artefak tambahan.
- `dataset_preprocessing.csv` : dataset yang sudah diproses.
- `screenshoot_dashboard.jpg` : placeholder screenshot dashboard.
- `screenshoot_artifak.jpg` : placeholder screenshot artefak.
- `requirements.txt` : dependency untuk menjalankan skrip modelling.
- `DagsHub.txt` : tautan DagsHub untuk advanced tracking.
- `DagsHub_config.md` : instruksi konfigurasi DagsHub.
